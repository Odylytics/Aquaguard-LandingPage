FAQ

Questions, answered.

Do I need to install an app?

No. AquaGuard works in any browser at aquaguard.vn. If you prefer, there is also a native iOS app — both connect to the same live rescue network.

Does it work with a weak signal?

SOS requests need a data connection, so AquaGuard includes one-tap registration for emergency 4G data packages from Viettel, Vinaphone and Mobifone, plus direct-dial shortcuts for 113, 114 and 115. Safety guides stay readable offline.

Is it free for residents?

Yes. AquaGuard is free for residents.

How do rescue teams join?

Create an account with the Rescuer role at aquaguard.vn, then form or join a rescue team. Rescuer access requires a team access code — use “Partner With Us” below to get one.

How is my location data used and protected?

Your location is used to send your SOS, route rescuers to you and, only if you connect with them, show your status to family. Access is limited by role and requires a signed-in account.
